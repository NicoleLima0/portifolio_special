# Fluent Emoji (Microsoft)

Os arquivos `.webp` desta pasta são derivados dos **Fluent Emoji** da Microsoft, na variante 3D.
Foram apenas redimensionados para 256 px e convertidos de PNG para WebP; o desenho é o original.

- Repositório: https://github.com/microsoft/fluentui-emoji
- Licença: MIT

Arquivos e a origem de cada um no repositório:

| Arquivo local   | Origem                                                        |
| --------------- | ------------------------------------------------------------- |
| `lupa.webp`     | `assets/Magnifying glass tilted left/3D/magnifying_glass_tilted_left_3d.png` |
| `foguete.webp`  | `assets/Rocket/3D/rocket_3d.png`                               |
| `raio.webp`     | `assets/High voltage/3D/high_voltage_3d.png`                   |
| `balao.webp`    | `assets/Speech balloon/3D/speech_balloon_3d.png`               |
| `sparkles.webp` | `assets/Sparkles/3D/sparkles_3d.png`                           |
| `coracao.webp`  | `assets/Purple heart/3D/purple_heart_3d.png`                   |
